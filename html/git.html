Git

  • git init: Инициализирует новый Git-репозиторий в текущей папке. Создаёт скрытую папку .git с внутренней структурой для отслеживания изменений.
  • git commit -m "сообщение": Фиксирует изменения в истории репозитория. Флаг -m позволяет сразу указать сообщение коммита..
  • git clone : Создаёт локальную копию удалённого репозитория по указанному URL.
  • git status: Показывает текущее состояние репозитория: какие файлы изменены, какие подготовлены к коммиту, а какие ещё не отслеживаются.
  • git branch <имя_ветки> Создаёт новую ветку с указанным именем. Сама по себе команда не переключает вас на новую ветку./
  • git merge <имя_ветки> Объединяет изменения из указанной ветки с текущей.
  • git push <имя_репозитория> <имя_ветки> Отправляет локальные коммиты в удалённый репозиторий.
  • git remote -v Показывает список настроенных удалённых репозиториев с их URL-адресами.
